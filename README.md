# Trabalho Avaliativo - HTML e Flexbox

Projeto Desenvolvido para a Tecnologias Web Turma 6N.

## Descrição

Página web responsiva contendo header, navbar, layout de 3 colunas 
(text, center e lado) e footer, desenvolvida com HTML e CSS 
utilizando Flexbox para o alinhamento dos elementos.

A página se adapta a diferentes tamanhos de tela por meio de media 
queries, empilhando as colunas em telas menores estilizado no CSS.

## Tecnologias utilizadas

- HTML
- CSS (Flexbox,...)
